# AGENTS.md

This file provides guidance to agents when working with code in this repository.

## Stack

Java 21, Spring Boot 4.1.1, Spring Security (stateless JWT), Spring Data JPA + Flyway, PostgreSQL, Lombok + MapStruct, JJWT 0.12.6, springdoc-openapi 3.0.0.

## Commands

```bash
# Build & test (all tests)
./mvnw verify

# Run tests only
./mvnw test

# Single test class
./mvnw test -Dtest=AuthServiceTest

# Single test method
./mvnw test -Dtest=AuthServiceTest#shouldRegisterNewUser

# Run application
./mvnw spring-boot:run
```

Integration tests (`@SpringBootTest`) require a live PostgreSQL instance matching `application.properties` defaults. They always need `@TestPropertySource` to supply `bookstore.security.jwt.secret` (min 32 bytes).

## Critical Conventions

**Lombok + MapStruct annotation processor order matters** — `pom.xml` wires them in a specific order: Lombok → lombok-mapstruct-binding → mapstruct-processor. Do not reorder.

**`@FieldDefaults(level = AccessLevel.PRIVATE, makeFinal = true)` + `@RequiredArgsConstructor`** is mandatory for all `@Service`, `@Component`, `@Configuration`, and `@RestController` classes. Never declare `private final` explicitly; never use `@Autowired`.

**DTOs are Java records**, not classes. All request/response types in `com.ibm.bookstore.dto` use `record`.

**Entities use UUID primary keys** assigned manually (`UUID.randomUUID()`) in the service layer, not auto-generated by Hibernate.

**`Clock` bean** (UTC, from `AppConfig`) must be injected wherever time-sensitive logic exists — never call `Instant.now()` or `LocalDateTime.now()` directly in services.

**`BookstoreProperties`** (`@ConfigurationProperties(prefix = "bookstore")`) holds business rules: gift-points rate, shipping flat rate, free-shipping threshold, cancellation window hours. Reference these instead of hardcoding.

## Exception Handling

All domain exceptions extend the project hierarchy and are handled in `GlobalExceptionHandler`, which returns RFC 7807 `ProblemDetail` responses. Available exceptions:
- `ResourceNotFoundException` → 404
- `BusinessRuleException` → 400
- `InvalidCredentialsException` → 401
- `UsernameAlreadyExistsException` / `EmailAlreadyExistsException` → 409
- `InsufficientStockException`, `OrderCancellationExpiredException`, `PaymentProcessingException` → domain-specific

Never throw a raw `RuntimeException`; always use or extend the existing hierarchy.

## Security

JWT is stateless. Public endpoints: `/api/v1/auth/**`, Swagger UI paths, and `GET /api/v1/categories|authors|publishers|books/**`. Everything else requires `Authorization: Bearer <token>`. The JWT secret is supplied exclusively via `JWT_SECRET` env var (never committed). Test minimum: `"test-secret-key-minimum-32-bytes!!"`.

## Testing Patterns

- **Unit tests**: `@ExtendWith(MockitoExtension.class)`, `@Mock` on repositories, real instances of `JwtUtils`/`PasswordEncoder` constructed manually in `@BeforeEach`.
- **Controller tests**: `@WebMvcTest` + `@Import({SecurityConfig.class, JwtAuthenticationFilter.class, JwtUtils.class, JwtProperties.class, GlobalExceptionHandler.class})` — the full security stack must be imported explicitly.
- **Integration tests**: `@SpringBootTest` against live Postgres; use `@TestMethodOrder(MethodOrderer.DisplayName.class)` for ordered scenarios.
- All test classes use `@DisplayName` on every `@Test` method.

## Package Structure

Singular package names only: `controller`, `service`, `repository`, `entity`, `dto`, `exception`, `security`, `config`. No plurals (`repositories`, `dtos`, etc.).

## Book Filtering

Book catalog filtering uses JPA `Specification` via `BookSpecification` (static factory, not a Spring bean). Always combine specs through `BookSpecification.buildFilter(...)`.
